## API Reference

### LessonPlanProps

| Prop                | Type                   | Description                                                |
| ------------------- | ---------------------- | ---------------------------------------------------------- |
| `subject`           | `string`               | Academic discipline or subject (e.g. "Mathematics").       |
| `gradeLevel`        | `string`               | Target grade or student cohort (e.g. "8th Grade").         |
| `lessonTitle`       | `string`               | Lesson plan title or topic.                                |
| `date`              | `string`               | Date the lesson is scheduled (e.g. "September 15, 2026").   |
| `teacherName`       | `string`               | Name of the instructor or educator.                        |
| `duration`          | `string`               | Estimated lesson duration (e.g. "50 minutes").             |
| `essentialQuestion` | `string?`              | Guiding inquiry question for student reflection.           |
| `objectives`        | `string[]`             | Learning objectives (SWBAT - Students Will Be Able To).    |
| `standards`         | `string[]?`            | Aligned educational standards codes (e.g. CCSS).           |
| `materials`         | `string[]`             | Required classroom resources and equipment.                |
| `sequence`          | `LessonSequenceItem[]` | Timed instructional table with activities and description. |
| `differentiation`   | `string[]?`            | Accommodations and modifications for diverse learners.     |
| `assessment`        | `LessonAssessment`     | Formative checks and summative evaluation methods.         |
| `homework`          | `string?`              | Extension or home assignment details.                      |
| `reflection`        | `string?`              | Post-instruction notes or blank teacher reflection prompt. |
| `accentColor`       | `string?`              | Primary theme accent for badges and borders.               |
